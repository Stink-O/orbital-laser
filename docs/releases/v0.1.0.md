The first release: a terrestrial orbital laser strike for [Horizon](https://github.com/ludovic111/horizon). Scope in with the Orbital Laser Designator, point at anything up to 200 blocks away, and a beam drops from orbit and digs a crater and a shaft down to bedrock.

## Install

1. Download **orbital-laser-v0.1.0.zip** below and unzip it.
2. Run `python3 install.py`. It copies the shader pack and the sound pack into Horizon's game folder (`~/.local/share/horizon`, or `$HORIZON_HOME`).
3. Turn them on: with the game closed, run `python3 install.py --enable`. Or in the game: **Options → Video Settings → Shader Packs → `orbital-laser-shader` → Apply**, then **Options → Resource Packs →** enable `orbital-sounds`.
4. Start Horizon through its control tool in a world with cheats on: `./horizon-ctl launch --world MyWorld --creative --wait`
5. Run `python3 strike.py --daemon`, press **9** for the Orbital Laser Designator, right-click and hold to look through the scope, aim, and keep holding for about a second.

**Stuck, or want an AI agent to do it?** Run `python3 strike.py --doctor`, or paste the prompt from the [README](https://github.com/Stink-O/orbital-laser#set-it-up-with-an-ai-agent) into your coding agent.

**Needs:** Horizon (with your own copy of Minecraft Java 26.3) and Python 3.8 or newer. If `horizon-ctl` isn't on your `PATH`, pass `--ctl /path/to/horizon-ctl` or set `HORIZON_CTL`.

> [!WARNING]
> **A strike is destructive and permanent.** It carves a crater about 20 blocks across and a shaft down to bedrock, and kills every mob and dropped item within 40 blocks (players are spared). Back up your world first.

> [!WARNING]
> **Early and experimental.** Developed and tested on one Linux PC (Fedora, NVIDIA), against the Horizon build released 2026-10-19. Windows and macOS are untested. The designator is a renamed spyglass and the strike is run by a script outside the game, because Horizon's mod API can't change the world yet.

## New

- **The strike:**
  - a red designator beam and converging reticle rings while it charges;
  - a plasma beam from orbit with twisting strands, surges, sparks and forked lightning;
  - a shockwave, camera shake and a molten crater glow;
  - a dark smoke column that rises and disperses.
- **Real terrain damage:**
  - a rough crater about 20 blocks across, trees stripped from a 24-block radius and the ground scorched to blackstone;
  - a shaft that funnels down and then runs straight to bedrock, with magma and lava at the bottom;
  - every mob and dropped item within 40 blocks killed, except players.
- **Custom sound design:** eight sounds synthesized from scratch (charge-up, lock-on, impact, plasma roar, rumble, crackle, rockfall, spool-down), layered with vanilla thunder.
- **No two strikes alike:** each one picks a colour (blue, magenta or green), power surges, beam sway and lightning density at random.
- **Point and fire:** the spyglass designator fires where your crosshair lands, up to 200 blocks away, with no block in reach needed.
- **Quiet:** nothing it does appears in chat.
- **Easy setup:** `python3 install.py --enable` installs and switches everything on, `python3 strike.py --doctor` checks the whole setup and says how to fix it, and the README has a copy-paste prompt that lets an AI agent do the setup for you on any system.
- **Tools:** an offline shader validator, a sound generator and a screenshot helper that recovers the real colours.
