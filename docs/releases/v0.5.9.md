A tidy-up release: one item instead of two, R only with that item in hand, and strikes that end when you leave the world.

<!-- DRAFT. Shipped first as the native build: the native session fills in the native install steps and assets below. -->

## Changes

- **The Orbital Remote is removed.** The Designator is the mod's one item now. `/orbital give` gives you the Designator, and the laser wheel opens with **R** while you hold it, or with `/orbital wheel` from anywhere. A Remote already in a world's inventory loads as an empty slot: it does nothing and breaks nothing.
- **R opens the wheel only with the Designator in hand.** With anything else in hand the mod ignores R, so the key is free for whatever else you use it for.
- **Leaving the world mid-strike ends the strike.** Before, a strike carried on into the next world you opened. Now its plan, the land changes still waiting and the sounds still to come are dropped as you leave. The chunks it forceloaded are let go the next time you play that world (about two seconds in), also if the game was closed mid-strike, so the save isn't left holding them.
- **Pausing holds the strike.** The pause menu stops the strike's clock, its land changes and its effects, and the game pauses its sounds and picks them up where they were when you go back.

## Known gap

- **Sounds can play on over the title screen (the Orbital Laser build of Horizon).** Horizon doesn't stop the sounds that are playing when you Save and Quit to Title, its own included (a music disc keeps going too). So a strike's sounds can carry on there until they end. The mod can't stop them once the world is gone; it needs a fix in Horizon. The native build stops them as you leave.

## Install

1. **Get the Orbital Laser build of Horizon, `orbital-mod-api-10` or newer** (the same as 0.5.8), from [Stink-O/horizon releases](https://github.com/Stink-O/horizon/releases).
2. Download **orbital-laser-v0.5.9.zip** below, unzip it, and with the game closed run `python3 install.py`.
3. Run `./play.sh` (a creative test world) or `./play.sh MyWorld`.
4. In the game, type `/orbital give`. Hold the Designator and press **R** for the laser wheel, and hold right-click with it on a target to fire.

### On regular Horizon (native)

0.5.9 also comes as a native mod for regular Horizon: no fork build and no `play.sh`. The [Horizon launcher](https://playhorizon.dev) (0.2.37 or newer) compiles it into the game.

1. Close the game. Put **orbital.hnmod** (the code and the content, one file) in your instance's `horizon-native-mods/` folder (make them if they aren't there; the Instances page's **Open folder** opens the instance). Give the native mod an instance of its own, not the Orbital Laser build's game folder.
   Coming from an earlier native test build? Delete its `orbital_laser.hnmod` from `horizon-native-mods/`, and `orbital-*.hmod` and `orbital-laser-native-*.hmod` from `horizon-mods/`, first.
2. On the launcher's Mods page, check Orbital Laser is on, and on the **Native build** row pick **Release build** (or run `horizon-launcher settings native-profile release`). It takes longer to build, but the game runs noticeably faster than with the default.
3. On the **Native build** row press **Build**, read the warning and choose **I trust these mods: build**. A native mod's code runs with full access to your computer, so only build it if you trust it.
4. Wait for the build (20 to 30 minutes the first time), play the instance, and type `/orbital give`.

It is built on upstream Horizon `c06a83b1c`, and the launcher builds it there whatever Nightly the instance has. What each system needs first: on **Linux** (tested) a C compiler, `pkg-config` and the ALSA and libudev development files (Debian/Ubuntu: `sudo apt install build-essential pkg-config libasound2-dev libudev-dev`; the launcher names what is missing); on **Windows** (x64) nothing, the launcher brings its own Rust and MinGW-w64; on **macOS** (Apple Silicon) Apple's Command Line Tools (`xcode-select --install`). Windows and macOS are build-checked (the code type-checks and every pass translates for DX12 and Metal) but not yet played. Intel Macs can't build native mods: the launcher has no Rust for them.

Known issues on the native build:

- **Far terrain can show the old land over a crater.** Land a strike changes while it is beyond your render distance keeps its old look in far terrain until you come within view of it (or reopen the world). The fix is in Horizon ([horizon-rust/horizon#8665](https://github.com/horizon-rust/horizon/pull/8665)); a higher render distance hides most of it until then.
- **The Hurricane draws no first-person hand.** While the Hurricane is under way, your hand and the item in it aren't drawn on the native build.

**Want an AI agent to do it?** Paste the prompt from the [README](https://github.com/Stink-O/orbital-laser#set-it-up-with-an-ai-agent) into your coding agent.

> [!CAUTION]
> **Photosensitivity:** the Hurricane's eyewall lightning, the Rod from God's impact frames (on by default; `/orbital impactframes off`), the Supercell's finale and other strikes' lightning and blasts are bright flashes.

> [!WARNING]
> **Strikes with terrain damage on are permanent.** Only fire them in a throwaway world, or switch terrain damage off on the wheel.

| `orbital-laser-v0.5.9.zip` | **the mod (`orbital/`), `install.py` and `play.sh`**: unzip and run `python3 install.py`; needs the Orbital Laser build of Horizon, `orbital-mod-api-10` or newer |
