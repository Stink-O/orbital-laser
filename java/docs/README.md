# Java port documentation

Notes on the Java Edition port of Orbital Laser (Fabric, Minecraft 26.3). Start with [../README.md](../README.md) to
install it and [../AGENTS.md](../AGENTS.md) for the short briefing.

| File | What it has |
|---|---|
| [DESIGN.md](DESIGN.md) | How the port is built and why: the plans, the shaders, Iris, far targets, sound, budgets |
| [PARITY-CHECKLIST.md](PARITY-CHECKLIST.md) | Every feature of the Rust mod (lasers, wheel, commands, settings), marked done, partial or not started |
| [BUILD-AND-TEST.md](BUILD-AND-TEST.md) | Build it, install it, test it, and what to look for |
| [MINECRAFT-26.3-NOTES.md](MINECRAFT-26.3-NOTES.md) | What was learned about Minecraft 26.3's rendering and command APIs |
| [ROADMAP.md](ROADMAP.md) | What is missing and a sensible order to do it in, including the other loaders |

[../PARITY.md](../PARITY.md) is the short status table; the checklist here is its detailed version. Keep both up to date.

The four screenshots in this folder (`1-tracking.jpg` to `4-impact-vanilla.jpg`) show the Payload on Fabric 26.3 with the
Tectonic terrain mod, Sodium, Voxy and the Complementary Reimagined shader pack.
